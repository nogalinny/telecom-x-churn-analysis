📊 Telecom X – Análise de Evasão de Clientes (Churn)
1. Introdução

A Telecom X é uma empresa do setor de telecomunicações que vem enfrentando um alto índice de evasão de clientes (churn). A evasão impacta diretamente a receita e o crescimento sustentável da empresa, tornando essencial compreender quais fatores influenciam o cancelamento dos serviços.

Neste contexto, fui contratada como Assistente de Análise de Dados para integrar a equipe de Data Science no projeto "Churn de Clientes". Meu papel neste desafio é atuar nas etapas iniciais do pipeline de dados, realizando extração, tratamento, transformação e análise exploratória dos dados (ETL + EDA), de modo que a equipe possa posteriormente avançar para modelos preditivos e estratégias de retenção.

2. Objetivo do Projeto

O objetivo principal deste projeto é:

Extrair dados de clientes a partir de uma API disponibilizada via GitHub;

Realizar o processo de ETL (Extração, Transformação e Carga);

Garantir a qualidade e consistência dos dados;

Conduzir uma Análise Exploratória de Dados (EDA);

Identificar padrões e fatores associados à evasão de clientes;

Gerar um relatório final com insights e recomendações para apoiar a redução do churn.

3. Tecnologias Utilizadas

Python

Pandas – manipulação e análise de dados

NumPy – suporte a operações numéricas

(Preparado para uso de Matplotlib e Seaborn em análises gráficas)
