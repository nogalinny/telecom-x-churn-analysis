# 📊 Telecom X – Churn Analysis

Projeto de análise de churn desenvolvido como parte do **Challenge Telecom X**, com foco em entender os fatores que influenciam o cancelamento de clientes e gerar insights estratégicos para retenção.

---

## 🎯 Objetivo
Identificar padrões de churn em clientes de uma empresa de telecomunicações, analisando variáveis como tipo de contrato, serviços contratados, forma de pagamento e cobrança mensal.

---

## 🧠 Principais Análises
- Distribuição de churn
- Churn por tipo de contrato
- Churn por tipo de internet
- Relação entre churn e cobrança mensal
- Insights estratégicos para redução de churn
