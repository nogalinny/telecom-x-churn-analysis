# 📊 Telecom X — Análise de Evasão de Clientes (Churn)

## 📌 Contexto do Projeto
A **Telecom X** enfrenta um alto índice de cancelamento de clientes (*churn*).  
Este projeto tem como objetivo **analisar os dados de clientes**, identificar os principais fatores associados à evasão e gerar **insights estratégicos** que apoiem decisões de negócio e futuras soluções preditivas.

O projeto foi desenvolvido seguindo boas práticas de **Análise de Dados** e **ETL**, servindo como base para modelos de Machine Learning.

---

## 🎯 Objetivos
- Entender o perfil dos clientes que cancelam o serviço
- Identificar padrões de churn por contrato, serviços e valores cobrados
- Preparar um dataset limpo e estruturado para modelagem preditiva
- Gerar insights acionáveis para retenção de clientes

### Conclusão

O churn está associado principalmente a **menor tempo de permanência**, **maior cobrança mensal** e ao serviço **Fiber Optic**.  
Esses fatores indicam maior risco de evasão nos primeiros meses de contrato e necessidade de atenção especial a clientes de maior ticket.
